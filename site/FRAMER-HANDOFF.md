# THINGBESIDE — Framer handoff

The HTML in this folder is the working prototype. Rebuild it in Framer using these settings.
All pages are generated by `build.py` in the project root. Edit content there, then run `python build.py`.

## Round 5: light redesign (reference: riseatseven.com)
The layout language follows riseatseven.com: warm off-white page, dark rounded panels inset 8px from the window, very large tight grotesk type, small photos set inside headings, a sticky work showcase, a hover services list, a stacked card deck, a drifting closing line and a giant footer wordmark. THINGBESIDE keeps its own red, the VR figure, the LED preloader and its copy. Nothing is copied from the reference's content, brand or imagery.

## Tokens
- **Fonts:** Switzer (Fontshare) 500 for headings, nav, buttons and labels. Inter 400–600 for body text.
- **Type (desktop / mobile):** Display 132 / 50px · Section title 104 / 46px · Large title 76 / 38px · Services list 52 / 28px · Label 22 / 18px · Body 17 / 16px. Letter-spacing −4.5% on display sizes, −3.5% on headings. Line-height 0.9–0.95 on big type.
- **Colours:** Page #EFEEEC · Surface #FFFFFF · Ink #111212 · Body text #3B3C3B · Muted #6C6D6A · Line rgba(17,18,18,.12) · Dark panel #111212 · Dark 2 #1C1D1D · Dark 3 #2A2B2B · Text on dark #F4F4F2.
- **Accent:** #F90918 for large shapes (hero disc, cursor circle, Step 03 card, marquee diamonds). #D10612 wherever small white text sits on red (badges, button hover fill, footer arrow), for AA contrast. No gradients.
- **Status:** available/success #16A34A (top bar dot, form success) · error #DC2626 (form only).
- **Radius:** 24px panels and cards · 16px project images and nav bar · 10px top bar · pills fully rounded. No shadows.
- **Spacing:** panels inset 8px from the window · inner padding 16–26px · section padding 160 / 88px · max width 1680px.

## Components and interactions in Framer
| Effect | Framer setup |
|---|---|
| LED preloader "THINGBESIDE" | Code component (port `preloader()` from assets/main.js). Runs once per session, then the dark curtain slides up with a curved bottom edge (1.15s, ease [0.76, 0, 0.24, 1]). |
| Top bar | White 36px bar above the hero: green pulsing dot, "Taking new projects · Book a free 15-minute call ↗". |
| Nav | Fixed. Over the hero it's transparent with white text and sits inside the hero card. After 40px of scroll it becomes a white rounded bar at the top (64px). Hides on scroll down, returns on scroll up. Red count badge on "Work". Menu button under 1100px opens a full-screen dark panel that wipes down. |
| Inline heading photos | Small rounded image (1.04em × 0.8em, radius 0.15em) placed between words. The hero one cycles through the four project photos every 1.8s. |
| Blur-in headings | Appear effect per word: Blur 12 → 0, Opacity 0 → 1, Y 0.28em → 0. 0.85s, ease [0.22, 1, 0.36, 1], 65ms stagger. Inline photos count as words. |
| Section reveal | Scroll-triggered appear: Y 28, Blur 6, 0.9s. Stagger 90ms in grids. |
| Pill button | Hover: fill wipes left → right (#D10612), label slides up to a duplicate, the ↗ arrow exits top-right and re-enters from bottom-left. Press scale 0.97. |
| Hero | Dark card, full viewport height. Centred eyebrow, two-line headline, sub-line. The VR figure sits bottom-centre in front of a large red disc; both follow the mouse (figure ±28px, disc the opposite way). Bottom-left: short pitch + two buttons. Bottom-right: location. Under 1100px it stacks: text, buttons, then figure. |
| Trades marquee | "Built for" + endless row of trades with red diamond separators, 40s loop, pauses on hover. |
| Count-up stats | 1.6s ease-out, once in view: 3 weeks · $590 · 14 days · 24 hrs. Also used on plan prices. |
| Featured work | Dark panel. Left (sticky): "Featured work", a rolling name list that centres the project whose card is in the middle of the screen (others fade by distance), "Explore all work" button. Right: 16:10 project cards. Under 1100px the list hides and each card shows its name and tags. |
| Project card | Search pill bottom-right ("electrician near me"). Hover: a panel in the project's colour wipes up from the bottom with the one-line result and name, the image scales 1.04, and a 104px red circle with ↗ follows the cursor. Opens the live site (Vercel link, set per project in build.py `CASES`). Hover colours: Fernmoor #2B3D54, Umbra #EB9843, Voltson #FFD23F, Saltmere #683526. |
| Services list | Two columns of 52px service names with dividers. Hover: row becomes a dark pill, the service photo fades in behind at 32%, text turns white, an ↗ slides in. |
| Big line | One huge line ("Hand-crafted design · AI-powered speed") with photos between phrases. Moves sideways as the section scrolls through the viewport (scroll-linked transform). |
| Process deck | Section pins for about 3.5 screens. Five cards (dark, white, red, dark, white) fly up from below and stack with slight rotations (−3°, 2.5°, −1.5°, 3.5°, −2°). Cards underneath shrink slightly. Counter "03 / 05" at the bottom. Reduced motion: cards sit in a normal column. |
| Pricing | Three cards, the middle one dark with a "Most popular" badge. Services page adds two wide cards (Rebuild, Updates). |
| FAQ | Large question rows with dividers. Round + button turns red and rotates 135° when open. One open at a time, 0.55s height ease. |
| Closing line | "Ready for a website that works?" at about 224px. Moves sideways with scroll while each letter rides a sine wave (up/down 0.1em, ±5° tilt). Code component in Framer. |
| Footer | Dark panel: call prompt, email pill with red arrow button, three link columns with vertical dividers, the THINGBESIDE wordmark scaled to fill the width, legal line. |
| Page transitions | Blur 10 + fade, 0.45s, between pages only. In-page links glide smoothly. |
| Smooth scrolling | Inertial wheel scrolling on desktop (lerp 0.1). Use Framer's Smooth Scroll component. Touch devices keep native scrolling. |
